# checkers
🎮 Features-
Human vs AI gameplay.
Three difficulty levels: Easy, Medium, Hard.
AI powered by minimax with adjustable depth.
Highlights selected pieces and valid moves.
Supports captures and king promotion.
Restart option after the game ends.


🕹️ Controls-
Left‑click to select and move pieces.
Press 1, 2, or 3 to change difficulty.
Press R to restart after a win/loss.


📸 Visuals-
The board uses alternating colors, highlights valid moves, and displays kings with a yellow ring for clarity.


📦 Installation-
Make sure you have Python 3 installed, then install pygame;
Code:
pip install pygame


▶️ How to Run-
Code:
python zgame.py


📁 Project Structure-
Code:
/project
│── zgame.py
└── README.md


🧠 AI Overview:
The computer uses a depth‑limited minimax search to evaluate moves. Higher difficulty levels increase the search depth, making the AI more challenging.
